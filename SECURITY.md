# Security

Signet holds people's signatures and personal details, so security bugs matter.

Please report them privately: use **Report a vulnerability** on the repository's Security tab (GitHub private advisory), not a public issue. You'll get an answer within a week.

What Signet promises: your profile and signatures stay in `~/.signet` on your own computer; the editor listens on `127.0.0.1` only and refuses requests not addressed to localhost or writes from other websites; Signet makes no network connections of its own.
